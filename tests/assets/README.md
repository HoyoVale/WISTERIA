# Model test assets

External model files are intentionally not committed yet. When the Assimp
importer is added, place the first static-model fixture at:

```text
tests/assets/models/Box.glb
```

Recommended fixture:

- Model: Khronos glTF Sample Assets — Box
- Direct download: https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Box/glTF-Binary/Box.glb
- Model index and attribution: https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Models.md
- License: Creative Commons Attribution 4.0 International
- Credit: Copyright 2017 Cesium

Keep the attribution above when redistributing the model. Local proprietary
game assets must not be added to this test directory unless their license
explicitly allows redistribution.
