## 2. 关键实现事实

- Bullet 3.25 `activate(true)` 内部仍走受保护的
  `setActivationState`，`DISABLE_DEACTIVATION` 下不会变为 ACTIVE_TAG；
  因此 canonical 激活统一使用 `forceActivationState(ACTIVE_TAG)`；
- `btRigidBody::setMotionState` 会把 motion state 的 transform 读回 body，
  所以 motion-state 选择只允许一次（Phase 1）；Phase 5 的
  `NormalizeCanonicalActivation` 不再重新选择；
- `btMatrix3x3(v0,v1,v2)` 构造参数是**行**向量，快照列主序 basis 恢复时
  必须显式行列映射，否则产生转置；
- `ReflectGlobalTransform` 读取 active motion state 内部 transform，
  Restore 后必须 `SyncActiveMotionStateToBodyTransform()` 才能把恢复的
  COM 写回骨骼；
- Restore Phase 6 必须执行 `model->UpdateNodeAnimation(true)`（正常步进
  的 after-physics 求值相位）；该实现发现已回填 R1.2B 契约 Phase 6；
- `physicsConfigurationFingerprint` 覆盖 gravity、solver 静态字段、
  per-body effective margin/dimensions、策略常量等；Final Test Fix 补齐
  `m_tau` / `m_friction` / `m_articulatedWarmstartingFactor` /
  `m_restingContactRestitutionThreshold` / `m_minimumSolverBatchSize` /
  `m_maxGyroscopicForce` / `m_singleAxisRollingFrictionThreshold` /
  `m_leastSquaresResidualThreshold` / `m_jointFeedbackInWorldSpace` /
  `m_jointFeedbackInJointFrame` / `m_reportSolverAnalytics`。

## 4b. 契约 T1-T23 覆盖映射（Final Test Fix）

聚合测试与契约用例的映射（不把“15 个测试”直接等同于“T1-T23 全量”）：

| 契约项 | 覆盖方式 |
| ---- | ---- |
| T1 / T1a | round-trip（全模式位级一致）；rotation round-trip 硬断言存在显著旋转（>0.5 偏差，约 29°；近 180° 需要专用 fixture，超出 core 范围） |
| T2 / T3 / T4 | idempotent / diagnostics / zero-step |
| T5 / T18 | divergent-history one-step（PhysicsHash 一致） |
| T6 | NaN force + NaN position |
| T7 | NaN/Inf basis、列长错误、非正交、det≈-1（world 与 interpolation 分别覆盖） |
| T8 / T10 / T11 / T12 | 数量 / schema / definitionMass 篡改 / 跨布局 |
| T9 | mode 篡改（同数量同质量但语义不同） |
| T9b | gravity 与 fixed timestep 配置指纹（margin/solver 由指纹字段覆盖，未提供热修改控制面） |
| T13 / T14 | canonical=false、force≠0、-0.0f force、Physics activation/deactivation 违规、tick 不匹配 |
| T15 | FollowBone 恢复后模式保持与位级一致 |
| T16 | frame tag 不匹配 + FollowBone transform 不匹配均拒绝 |
| T17 | 恢复后直接 Step 返回 InvalidState |
| T19 | 测试钩子制造真实 DISABLE_DEACTIVATION 历史 |
| T20 | 故障注入 → Poisoned → PrepareFrameZero 恢复 |
| T21 | 1000 次 round-trip 无漂移 |
| T22 | Mode 2 独立断言：body transform + 骨骼 local + 位级 round-trip |
| T23 | 测试钩子把 FollowBone definitionMass 置为非零并验证仍按 kinematic |

已知缺口（如实记录，不冒充闭合）：T1a 的“近 180°”用显著旋转替代；T9b
的 margin/solver 修改没有热修改控制面，仅靠指纹字段与构造参数覆盖。
