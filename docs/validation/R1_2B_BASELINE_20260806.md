## 2. 关键实现事实

- Bullet 3.25 `activate(true)` 内部仍走受保护的
  `setActivationState`，`DISABLE_DEACTIVATION` 下不会变为 ACTIVE_TAG；
  因此 canonical 激活统一使用 `forceActivationState(ACTIVE_TAG)`；
- `btRigidBody::setMotionState` 会把 motion state 的 transform 读回 body，
  所以 motion-state 选择只允许一次（Phase 1）；Phase 5 的
  `NormalizeCanonicalActivation` 不再重新选择；
- `btMatrix3x3(v0,v1,v2)` 构造参数是**行**向量，快照列主序 basis 恢复时
  必须显式行列映射，否则产生转置；
- `ReflectGlobalTransform` 读取 active motion state 内部 transform，
  Restore 后必须 `SyncActiveMotionStateToBodyTransform()` 才能把恢复的
  COM 写回骨骼；
- `physicsConfigurationFingerprint` 覆盖 gravity、solver 静态字段、
  per-body effective margin/dimensions、策略常量等。
