## 2. 四子步实验（Bullet 3.25，float 精度）

探针直接读取 Bullet protected `m_localTime`，统计
`stepSimulation(1/30, 10, 1/120)` 的真实返回值：

```text
120 帧：    min=4 max=4 non4=0，帧边界 accumulator 全为 0
10000 帧：  min=4 max=4 non4=0，帧边界 accumulator 全为 0
动态盒体同时确认求解路径真实执行（y 坐标持续变化）
```

结论：保留现有 Saba 相位，`StepMotionFrameExact` 直接调用完整
`UpdatePhysicsAnimation(1/30)`；不需要 vendored 专用精确步进路径。

## 4b. R1.2A Fixup（第二轮审查后）

审查复现两个阻断点后完成集中 Fixup：

- `EvaluateTick` 改为默认实现（非纯虚），修复测试替身编译遗漏；
- **顶点未定义行为根因 = 双 GLM ODR 冲突**：引擎 TU 用
  `third-party/glm`（GLM 1.0.3），Saba 库用自带 GLM 0.9，同名内联符号
  不同语义导致链接器随机选取实例化，矩阵乘法读到错误布局。最终修复为
  **WISTERIA 持有 GLM 1.0.3，Saba 链接 `glm_headers`**（不是引擎降级到
  0.9），第三方后端不反向决定引擎数学 ABI；
- 步进状态机（InvalidState / NonSequentialFrame / DeterminismViolation）；
- ReplayConfig 与 live Bullet 配置绑定 + 每帧 4 子步/0 accumulator 校验；
- Canonical Reset 补齐 `updateSingleAabb`；
- Morph override API 拆分（SetMorphWeight 恢复旧语义）；
- Snapshot 能力位拆为 capture/restore/canonicalRestore；
- Hash 加固（valid、数量、finite、index 严格递增）；
- Impulse stop-control 改显式分量判零（GLM 0.9 的 `memcmp` 相等语义）。
- Canonical Reset 恢复动态刚体真实 Dynamic 模式并清零
  activation/deactivation 历史；
- 非法骨骼索引改为 identity 回退（不再钳制到 bone 0）；
- Pose Hash 增加数量一致性与 finite 校验。
