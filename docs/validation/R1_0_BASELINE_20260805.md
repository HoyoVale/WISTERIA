## 3. 测试结果

### Windows（MSVC RelWithDebInfo）

CORE 档（`WISTERIA_TEST_FULL_ASSETS=OFF`）：

```text
CTest 4/4 通过
wisteria.integration：20 PASS（core）+ 17 NOT_CONFIGURED（fullAssets 整组跳过）
0 SKIP / 0 FAIL
```

FULL_ASSETS 档（`WISTERIA_TEST_FULL_ASSETS=ON`）：

```text
CTest 4/4 通过
wisteria.integration：37 PASS（20 core + 17 fullAssets 真跑）
0 SKIP / 0 NOT_CONFIGURED / 0 FAIL
```

### Linux（WSL + llvmpipe）

CORE 档：

```text
CTest 4/4 通过
wisteria.integration：20 PASS（core）+ 17 NOT_CONFIGURED（fullAssets 整组跳过）
```

FULL_ASSETS 档（RelWithDebInfo，避免 Debug 无优化导致的物理数值漂移）：

```text
CTest 4/4 通过
wisteria.integration：37 PASS（20 core + 17 fullAssets 真跑）
```

注意：Linux FULL_ASSETS 档必须使用 `RelWithDebInfo`（或 Release）构建。
默认（空）构建类型是 Debug 无优化，Saba/Bullet 物理基线会因数值差异触发
`Compat baseline physics runaway`，属构建配置问题而非代码回归。

### 档位语义验证（Windows，实测）

- `WISTERIA_TEST_FULL_ASSETS=ON` 且资产缺失 → `[FAIL] FULL_ASSETS fixture
  missing: production-pmx-yixuan`（硬失败，不允许 SKIP）；
- 默认档即使资产存在，fullAssets 用例也整组 `[NOT_CONFIGURED]`
  （CORE 结果与机器资产无关）；
- core 资产缺失（如 `extended_morph.pmx`）→ `[FAIL] core fixture missing`
  （任何档位均不允许 SKIP）；
- 资产存在时两档均执行真实断言。

## 4. 修复记录

### Direct PMX MorphState 断言（R1.0 补丁自带冲突）

- 补丁前 HEAD 已存在断言 `morphInstance.HasMorphState()`；
- 补丁将 backend 驱动 PMX 的 Morph 所有权移入 Saba Runtime，断言冲突；
- 补丁验证环境缺 `仪玄.pmx`，用例 SKIP 掩盖冲突；
- 已改为验证 `ModelInstance` + `saba-mmd` runtime + 实例 Mesh +
  命名 Morph 经 runtime 控制；
- 双平台该用例均 `[PASS]`（真跑）。

### Converted MMD GLB 路径错误（R1.0A 发现）

- 测试引用 `tests/assets/models/仪玄/仪玄.glb`，实际目录为
  `仪玄_glb`，用例长期 SKIP；
- 已修正路径，修复后双平台 `[PASS]`（真实导入 21 mesh / 21 material /
  6 texture 断言通过）。

### Native ABI MMD control 静默 return（R1.0A 发现）

- 资产缺失时 `return;` 直接通过（绿灯陷阱）；
- 改为 `RequireFullAsset`，缺失时按档位 FAIL / NOT_CONFIGURED。

### manifest 权威化 / 档位分离 / ABI 矩阵（R1.0A.1）

- `fixtures.json` 此前未被测试读取，测试仍手写路径；已改为
  `FixturePath(id)` 唯一取路径来源；
- CORE 档此前被本机资产污染；已改为 fullAssets 整组 NOT_CONFIGURED；
- ABI 矩阵此前漏 3 个导出（91/94）；已补全并脚本化。

## 7. 复现命令

```bash
# Windows
cmake -S . -B build -DWISTERIA_BUILD_NATIVE=ON
cmake --build build --config RelWithDebInfo
ctest --test-dir build -C RelWithDebInfo

# Windows FULL_ASSETS 档位
cmake -S . -B build-fullassets -DWISTERIA_BUILD_NATIVE=ON -DWISTERIA_TEST_FULL_ASSETS=ON
cmake --build build-fullassets --config RelWithDebInfo
ctest --test-dir build-fullassets -C RelWithDebInfo

# Linux（WSL）
export LIBGL_ALWAYS_SOFTWARE=1
cmake --build build-linux
ctest --test-dir build-linux

# ABI 矩阵校验
python script/gen_abi_safety_matrix.py --check
```
